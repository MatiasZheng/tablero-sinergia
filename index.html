Reagendada (criterio de Gerencia): N Agend. ≥ 2 o motivo de reagenda registrado; N Agend. = 1 es el primer agendamiento. % Reagendadas = OS reagendadas ÷ OS creadas. % Reagenda operativa = OS con motivo Demora de contratista, Técnico, Infra o Reag. rápido ÷ OS creadas; meta TAP: reducción relativa ≥20% vs línea base. SLA soporte = soportes ejecutados en ≤24 h corridas desde la creación ÷ soportes ejecutados; SLA instalación = instalaciones en ≤48 h ÷ instalaciones ejecutadas; meta: igual o mejor que la línea base. Mediana y P90 en horas creación → ejecución. % SLA ZOY = ejecutadas antes del Prazo Data ÷ ejecutadas. % Garantía = OS con el campo Garantia cargado ÷ OS creadas.
